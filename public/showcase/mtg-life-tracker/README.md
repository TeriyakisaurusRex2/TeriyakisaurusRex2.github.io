MTG Game Assistant is a life tracker for Magic: The Gathering that goes beyond a single phone on the table. A tablet in the middle of the table is the shared display, and everyone else can join from their own phone.

## Built so far

- Life, commander damage with partners, poison and custom counters
- Seat layouts for 2 to 8 players, each rotated to face its player, plus a custom layout editor
- Turn tracking, dice, a game timer, full undo and redo, and game history
- Phones join by QR code and control their own seat, with a guarded mode where the host owns life totals

## Next

- A reminder engine for end-step triggers, monarch, initiative and other things that are easy to forget
